# تطبيق المسابقة الثقافية (Cultural Competition App)

تطبيق ويب تفاعلي للمسابقات الثقافية، مصمم بأسلوب عصري وسهل الاستخدام.

## هيكل المجلد
- `index.html`: الملف الرئيسي (هيكل الصفحة).
- `assets/css/style.css`: ملف التنسيق والجمالية.
- `assets/js/script.js`: ملف البرمجة وقاعدة بيانات الأسئلة.

## طريقة التشغيل
1. قم بفك الضغط عن المجلد.
2. افتح ملف `index.html` في أي متصفح حديث (Chrome, Firefox, Edge).

## دليل الاستخدام
- **المشرف (Supervisor):** يدخل بالرمز السري (`youssef98`) للتحكم في الأسئلة، إطلاق المؤقت، ومنح النقاط.
- **المشارك (Participant):** يختار رقم الفريق وينتظر ظهور الأسئلة التي يطلقها المشرف.

## ملاحظة تقنية هامة
هذا الإصدار مصمم للعمل على **نفس الجهاز** (المتصفح) للمحاكاة. إذا كنت ترغب في تشغيله عبر أجهزة مختلفة في شبكة حقيقية، ستحتاج إلى ربطه بقاعدة بيانات حقيقية (مثل Firebase أو Supabase).

## الأسئلة
يمكنك تعديل الأسئلة مباشرة من ملف `assets/js/script.js` ضمن كائن `QUESTIONS`.
